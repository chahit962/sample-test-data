# sample-test-data

A small set of clearly labeled test records for trying out CSV import, parsing, filtering, and validation workflows.

## Test data

[`data/sample_records.csv`](data/sample_records.csv) contains three fictional product inventory rows. The values are synthetic examples only and do not describe real people, products, or transactions.

Columns: `record_id`, `name`, `category`, `quantity`, and `active`.

The first CSV line is a comment labeling the file as sample test data; remove that line if your CSV parser expects the header on line one.

## Use

Use this file for demos and local tests. Do not treat these example records as production data.
